1. agent は「会話するAI」から「仕事を最後まで進める surface」へ移った

根拠: OpenAI / Google 公式領域: Agents / Workflows / Enterprise

今週の最も強い構造変化は、agent が補助UIではなく、実際に作業を進める実務 surface として整理されたことです。OpenAI は ChatGPT Work を長時間タスクとアプリ横断作業の面で押し出し、Presence では承認済みアクション、評価、エスカレーション込みの導入面を明示しました。Google 側でも Gemini アプリの利用規模拡大と Managed Agents の hooks、予算制御、background execution が並び、consumer と developer の両面で「動くAI」の土台が厚くなっています。

5. 新しいフロンティアモデル一般公開が少ない週ほど、来週の比較軸は運用条件になる

根拠: 当週アーカイブ総合領域: Market Structure / Watchlist

今週は OpenAI / Anthropic / Google の新しい一般公開フロンティアモデル自体は週の中心ではありませんでした。ただし重要度が低いのではなく、各社がその前段として、agent surface、公開条件、安全判断、価格、配布、計測を詰めている週だったと読むべきです。次の大きいモデル更新が出る時、比較材料はベンチマークだけでは足りず、公開範囲、承認フロー、支払い構造、移行コストまで含めて見る必要があります。

何が変わったか

  • 新しく主役化: 仕事を終わらせる agent surface と、その承認、停止、予算、監査の運用面が前面に出ました。
  • 重要度が上昇: open-weight か非公開か、中国向け専用設計か共通配布かのような distribution choice が、性能差と同格になりました。
  • 中国で継続: AI は配布提携、資本支出、価格改定、退役管理まで含めた産業運用の競争になっています。
  • 削ったもの: 単発の資金調達や弱い噂は外し、来週も効く公開判断、配布条件、運用計測だけを残しました。

開発者への示唆

  • agent 導入: 長時間動く agent は、権限、停止条件、再実行、エスカレーションを先に決めてから広げる。
  • model lifecycle: モデル名を固定した自動化は棚卸しし、廃止予定と代替モデルを runbook 化する。
  • cost visibility: モデル別の input / output / cache を見えるようにし、品質比較と請求説明を同じ単位で揃える。
  • open-weight 評価: 自由度だけで採用せず、政府調達や社内利用で必要な監査、ログ、用途制限まで先に確認する。
  • 中国向け判断: 中国系モデルや中国市場向け機能は、性能より先に提供地域、提携先、退役日、規制条件を確認する。
  • portfolio 設計: 1社1モデルで固定せず、closed と open-weight、グローバルと中国向けを使い分ける前提で比較表を持つ。
