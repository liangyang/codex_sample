MAI-Code-1.1-Flash available in GitHub Copilot

出典: GitHub Changelog

公開日: 2026-08-11

カテゴリ: API / Models

読む価値: 小型のコーディング向けモデルが、画像理解つきで Copilot に入ります。価格も旧モデルより大きく下がり、軽量ワークフロー向けの選択肢が明確になりました。

開発者への示唆: 低コストで回す自動化や、IDE・CLI・クラウドエージェントのモデル選択を見直すタイミングです。企業設定では有効化が必要なので、使える前提にしない方が安全です。

試すなら: 管理ポリシーを確認し、画像を含む小さなコーディング課題で旧モデルと比較してください。コストと品質の差を先に把握すると判断しやすいです。

Copilot on web expands conversation controls

出典: GitHub Changelog

公開日: 2026-08-10

カテゴリ: Infra / UX

読む価値: web 上の Copilot Chat で会話の最小化、再開、トークン消費の可視化ができるようになりました。長めのやり取りを切らさず使うときの体験が改善します。

開発者への示唆: ブラウザでの調査やレビュー作業が多い人ほど効きます。会話の継続性と上限意識が同時に上がるので、使いすぎも抑えやすくなります。
