GitHub Actionsの大量検索は期間で絞る

GitHub Changelog / 2026-09-25 / API・Infra

読む価値: ワークフロー実行の検索結果が2,500件を超える場合、正確な件数の代わりに「2,500+」を返す変更です。タイムアウト由来の誤った件数を避け、検索性能を安定させます。

開発者への示唆: 件数フィールドを完全な総数として扱う監査・集計スクリプトは修正が必要です。結果は最大1,000件ずつページ取得できるため、全件取得には検索条件の分割が欠かせません。

試すなら: 2,500件を超える履歴のあるリポジトリで、期間を分けた検索とページ走査を試し、集計が重複・欠落しないことを確認します。
