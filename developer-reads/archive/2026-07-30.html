Governance Infra

Default model enablement for Copilot Business and Enterprise

出典: GitHub Changelog / 公開日: 2026-07-29 JST

読む価値: 既定の model enablement が追加され、新しい GA モデルを管理者が個別に毎回有効化しなくてもよくなりました。運用負荷が下がり、モデル切り替えの追従がしやすくなります。

開発者への示唆: 便利さは増しますが、モデルの既定値が変わると品質、コスト、応答時間も動きます。組織での標準モデルを決めておかないと、チームごとの再現性が崩れやすいです。

API Infra

GitHub Models is being fully retired on July 30, 2026

出典: GitHub Changelog / 公開日: 2026-07-30 JST

読む価値: GitHub Models の playground、model catalog、inference API、BYOK が終了しました。GitHub 側のモデル実験や推論面に依存していた構成は、早急な置き換えが必要です。

開発者への示唆: モデル実験基盤の終了は、プロンプトより先に運用と移行計画を問います。周辺ツールや CI で GitHub Models を参照している場合は、影響範囲が広がりやすいです。

試すなら: 使っている repo と workflow を検索し、GitHub Models 依存を洗い出して代替 API へ切り替えてください。
