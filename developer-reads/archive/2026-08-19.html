GitHubの資格情報をトークン種別ごとに失効

GitHub Changelog / 2026-08-18 / Infrastructure・Safety

読む価値: セキュリティ事故時に、PAT・SSHキー・OAuthトークンなどを種類別に失効できるREST APIと監査ログ対応を確認できます。

開発者への含意: すべての資格情報を一斉に止めず、侵害範囲を絞ってサービス停止や復旧負荷を抑えられます。エージェントやCIの資格情報も棚卸ししやすくなります。

試すなら: インシデント手順にトークン種別ごとの失効API、監査ログ確認、影響を受けた利用者への通知を追加し、復旧用の短期資格情報を別経路で用意する。
