今日読むべき4本

プロンプトキャッシュを12時間保持する

出典: OpenAI API Changelog · 2026-10-20 · API / Inference

読む価値: 共有の指示やツール定義を長く再利用でき、数時間空くリクエストにもキャッシュを使えます。書き込み費用は通常入力の2.5倍です。

開発者への示唆: 再利用間隔が長い対話やバッチに向きますが、ヒット率が低いと割高になり得ます。12時間と30分のキャッシュ書き込みを分けて使用量と実費を計測できます。

試すなら: 固定の指示・ツール定義を先頭に保ち、実トラフィックでキャッシュヒット率、書き込み量、遅延、入力費用を30分と12時間で比較する。

エージェント用モデル方針をREST APIで管理する

出典: GitHub Changelog · 2026-10-19 · Agents / API

読む価値: 企業、組織、チーム、エージェントアプリ単位のモデル利用方針をGET・PATCHで取得・更新できるようになりました。

開発者への示唆: 組織ごとの許可設定を管理画面や構成管理へ組み込み、手作業のずれを抑えられます。上位方針からチームへ管理権限を委譲する運用にも対応します。

試すなら: テスト組織で現在の方針を取得し、変更案をレビュー可能な構成ファイルからPATCHして、反映結果と委譲範囲を照合する。

脆弱な依存パッケージの実バージョンをAPIで取得する

出典: GitHub Changelog · 2026-10-20 · API / Safety

読む価値: Dependabotのアラートに、リポジトリ側で検出された依存バージョンを返すフィールドが追加されました。ロックファイル解析や別のGraphQL照会を省けます。

開発者への示唆: 脆弱性ダッシュボードやチケット連携で、影響中の実バージョンをそのまま示せます。値がない場合や複数バージョンを包含する場合の扱いは必要です。

試すなら: アラートREST APIとWebhookの新フィールドを取り込み、null・長い制約・複数バージョンを含む通知の表示を確認する。

パッケージ導入時に悪性コードを遮断する

出典: GitHub Changelog · 2026-10-20 · Safety / Infra

読む価値: CI実行環境やコーディング支援ツールからパッケージレジストリへの通信を中継し、メタデータとダウンロードをポリシーに照らして検査します。

開発者への示唆: インストール時に認証情報を盗む攻撃への防御を、パッケージ実行後の検出より前に置けます。現在はEnterprise Cloud向けプレビューでnpmのみが対象です。

試すなら: 検証用のCI環境でレジストリ経由を切り替え、許可・遮断の挙動、例外申請、ビルド再現性を確認する。
