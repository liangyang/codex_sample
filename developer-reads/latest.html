出典: Google Cloud Blog · 2026-10-19 · Evals

読む価値: 同一入力への採点の安定性、人手との一致、複数評価器の意見差という三つの確認軸を整理しています。

分離型推論でKV転送を先行させる

出典: AWS Machine Learning Blog · 2026-10-19 · Inference / Infra

読む価値: KVブロックの転送先を先に登録し、生成側の待ち時間と転送準備を並行化する設計を、構成とベンチマークで解説します。

開発者への示唆: PrefillとDecodeを分けた推論では、モデル計算だけでなくキャッシュ移送の同期も初回応答と生成速度を左右します。掲載結果は特定構成での計測値です。

試すなら: 自分のモデルとネットワークで転送あり・なしを比較し、初回トークン時間、出力速度、転送時間を同じ負荷条件で測る。
