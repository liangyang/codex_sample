Safety Infra

GitHub Actions holds potentially malicious workflows for approval

出典: GitHub Changelog / 公開日: 2026-07-28 JST

読む価値: public repository の workflow に対して、疑わしい run を自動で止めて write 権限のある collaborator の承認を要求する仕組みが入りました。CI/CD の既定信頼モデルが一段厳しくなります。

開発者への示唆: もはや「workflow があるから動く」前提ではなく、実行前に止まるケースを設計に織り込む必要があります。供給網攻撃の入口が GitHub 側で狭まる一方、運用側では承認フローと通知設計が重要になります。

試すなら: public repo の workflow を棚卸しして、承認待ちになった時の担当者・通知先・復旧手順を確認してください。

Safety Infra

Dependabot alerts on malicious packages across more ecosystems

出典: GitHub Changelog / 公開日: 2026-07-28 JST

読む価値: OpenSSF の malicious-packages データが GitHub Advisory Database に取り込まれ、npm や PyPI などで malware advisory の検出範囲が広がりました。依存関係の監視が一段実戦的になります。

開発者への示唆: パッケージ名の typo-squat や悪性公開への対策は、スキャン対象の広さで差が出ます。Dependabot の alert を「バージョン更新通知」ではなく、supply chain の監視レイヤーとして扱うべきです。

試すなら: `type:malware` フィルタで今の repo 群を見直し、重要な dependency set がどの ecosystem までカバーされているか確認してください。

Enterprise managed settings in the GitHub Copilot app and Copilot cloud agent

出典: GitHub Changelog / 公開日: 2026-07-27 JST

読む価値: Copilot app と cloud agent が、CLI や VS Code と同じ managed settings を読むようになりました。plugin、marketplace、approval prompt、auto model selection を横断して統制できます。

Manage GitHub Copilot app access with a dedicated policy

Coding Agents Infra

GitHub Copilot for JetBrains adds improved OpenTelemetry configuration and model management

出典: GitHub Changelog / 公開日: 2026-07-27 JST

読む価値: JetBrains 側で OpenTelemetry export、token 上限、model management、MCP server 接続が強化されました。IDE 内の agent work を観測しやすく、コスト制御もしやすくなります。

開発者への示唆: ローカル agent の価値は、速度だけでなく「何をどれだけ使ったか」が見えることにあります。観測と model policy があると、custom endpoint や BYOK の比較もしやすくなります。

試すなら: OTel export を有効にして、同じ task で token 消費と失敗箇所を比較し、`maxInputToken` と `maxOutputToken` の調整効果を見てください。
