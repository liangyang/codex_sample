OpenAIがGPT-6.1 Solを公開、最上位モデルに近い能力を低価格で提供

根拠: 公式発表扱い: 公開済み。価格・性能の記述は提供元の説明領域: モデル / API

要点: OpenAIは10月21日、コーディング、コンピューター操作、専門業務向けのGPT-6.1 Solを発表しました。同社は上位のGPT-6 Astraに近い能力を、標準API入出力トークン価格の5分の1で提供すると説明しています。

なぜ重要か: 高性能モデルの選択肢が増え、企業は一律に最上位モデルを使うより、タスクごとに品質・速度・単価を配分しやすくなります。

見るべき点: 実際の利用可能地域、価格表、レイテンシ、独立したタスク別評価。

AnthropicがAgent Skills標準を中立財団へ寄贈

根拠: 公式発表扱い: 寄贈を発表。今後の仕様運営はコミュニティ段階領域: エージェント / 標準化

要点: Anthropicは10月22日、エージェントに手順や専門知識を与えるAgent Skills標準をLinux Foundation傘下のAgentic AI Foundationへ寄贈すると発表しました。同社はChatGPT、Cursor、GitHub Copilot、VS Codeなど70超の環境に統合されたと説明しています。

なぜ重要か: エージェント向けの指示・スクリプト形式が単一ベンダー管理から中立的な運営へ移ることで、ツール間の移行や共有の基盤になり得ます。

見るべき点: 正式な変更提案・版管理、安全ガイダンス、各製品の互換性。

根拠: 公式発表扱い: 社内環境の自己報告。実利用環境との違いに注意領域: AI安全 / サイバー

見るべき点: 第三者評価、再発防止策の検証、検証環境と顧客向け環境の境界。

Microsoftの診断AI研究がScienceに掲載、段階的診断ベンチマークも公開

根拠: 公式発表 / 学術誌扱い: 研究評価。臨床現場での有効性を示すものではない領域: 医療AI / 評価

要点: Microsoftは10月22日、逐次的な問診・検査選択を測るSDBenchと診断システムMAI-DxOの研究がScienceに掲載されたと発表しました。複雑なNEJM症例では同社システムが83%、比較対象の医師が参考資料ありで36%と報告されています。

なぜ重要か: 単一の診断回答ではなく、追加情報をどう求め検査費用をどう抑えるかを評価する枠組みは、医療AIの実務性能を測る方法に関わります。

見るべき点: 対象症例の選定、独立再現、前向き臨床評価、専門医チームとの比較。

OpenAIのモデルとCodexをGoogle Cloud Model Gardenへ追加する計画

根拠: 公式発表扱い: 一般提供は今後数週間の予定。現時点では計画領域: クラウド / API
