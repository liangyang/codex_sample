1. 腾讯云がDeepSeek V4の週末料金を終日空闲時段価格へ統一

根拠: 企業公式発表扱い: 確認済み／継続確認領域: API / Pricing / Inference

腾讯云は8月26日、DeepSeek V4原厂直供の全モデルについて、北京時間8月29日（土）0時から、平日は従来のピーク・空闲区分を維持し、土日を終日空闲時段価格で計算すると告知しました。対象にはDeepSeek-V4-Flash 0731、DeepSeek-V4-Pro 0813、DeepSeek-V4-Flash-Vision-Expが含まれます。

これはモデル能力の更新ではなく、推論需要を時間帯で平準化する料金変更です。週末バッチ、評価、開発環境ではコスト低下の可能性がありますが、実価格、利用量、サービスレベルは料金表と契約条件で確認します。

2. 腾讯云がYT-VITAを10月15日に終了、HY-Visionなどへの移行を案内

根拠: 企業公式発表扱い: 確認済み／継続確認領域: Model Lifecycle / API

腾讯云は8月26日、TokenHubと智能体开发平台 ADPのYT-VITA（modelパラメータ youtu-vita）を、北京時間10月15日0時から終了すると告知しました。代替案としてHY-Vision-2.0-Instruct、HY-Vision-1.5-Thinking、HY-Vision-Videoなどを案内し、利用者にモデル名の変更、価格・额度・適用範囲の確認を求めています。

モデルの提供終了は、性能競争とは別の実務リスクです。画像・動画処理の入力、出力、品質、レート制限が代替先で同じとは限らないため、停止日より前に切替テストと残高処理を終える必要があります。

3. 政府系整理がAIを算力・ロボット・産業現場の組み合わせとして可視化

根拠: 政府系発表／主要報道扱い: 継続確認領域: Infrastructure / Embodied AI / Industry

数字中国の8月27日整理は、国家級AI開源社区のユーザーが1,100万人超、国内AI開源大模型の世界累計ダウンロードが100億回超、智能算力規模が2,185 EFLOPS、算力枢軸周辺の算力大通道が70本超とする政府説明を紹介しました。同じ整理では、2026年上半期の中国人形ロボット出荷量が4万台超、世界比率97%とする報告も紹介されています。

これらは公表資料に基づく産業指標であり、個別モデルの利用率やロボットの稼働収益を直接示すものではありません。数字の定義、集計範囲、実際の導入・稼働を分けて確認します。
